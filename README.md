# Chai aur Code - JavaScript Series ☕

A beginner-friendly JavaScript tutorial series walking through **25+ topics** — from `console.log()` to Classes & OOP. Each file teaches one concept with a simple, runnable example.

## 🚀 Quick Start

```bash
node "1basic console.js"   # start here
# then 2, 3, 4... all the way to 25
```

## 📚 Learning Roadmap

### Phase 1: Basics (Files 1–7)
| File | Topic | What You'll Learn |
|------|-------|-------------------|
| `1basic console.js` | Console | Print with `console.log()` |
| `2let.js` | let | Block-scoped variables (reassignable) |
| `3var.js` | var | Function-scoped variables (old way) |
| `4const.js` | const | Block-scoped constants (not reassignable) |
| `5var.js` | Objects | `{key: value}` — store related data |
| `6operators.js` | Operators | `+`, `===` (strict equality) |
| `7conditional statement.js` | Conditionals | `if / else` branching |

### Phase 2: Loops & Functions (Files 8–15)
| File | Topic | What You'll Learn |
|------|-------|-------------------|

| `9decrese order for loop.js` | for loop | Count down: `for(let i=10; i>0; i--)` |
| `10while.js` | while | Loop while condition is true |
| `11do while.js` | do while | Run once, then check condition |
| `12reusable function.js` | Functions | `function name(params) { return }` |
| `13push.js` | Arrays | `.push()` — add items to an array |
| `14functions.js` | Functions | Two parameters, return a result |
| `15Arrow functions.js` | Arrow | `const fn = (x) => x * 2` |

## 💪 Practice Challenges

Try these after each phase:

- **Phase 1:** Create a `car` object with properties. Write an `if` to check if it's older than 2010.
- **Phase 2:** Write an arrow function `isEven` that returns `true` if a number is even.
- **Phase 3:** Add a button to `one.html` that changes background color on click.
- **Phase 4:** Use `.filter()` to get even numbers from `[1,2,3,4,5,6]`.
- **Phase 5:** Create a `Car` class, then extend it with `ElectricCar` that has `batteryLife`.

## 🗺️ Topic Map

```
Console → Variables (let/var/const) → Objects → Operators
→ Conditionals → Loops (for/while/do-while) → Functions
→ Arrays → Arrow Functions → DOM → Events
→ JSON → Modern JS → Error Handling → Async
→ Array Methods → Classes → Inheritance
```
